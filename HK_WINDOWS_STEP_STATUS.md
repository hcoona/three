## Shared helper scripts introduced in this loop

- `eng/scripts/hk_exec.py`
    - Normalizes quoted file paths and safely forwards command + file args.
    - Adds per-file start time, heartbeat, timeout, and timeout process-tree kill (`HK_EXEC_TIMEOUT_SECONDS`, `HK_EXEC_HEARTBEAT_SECONDS`, `HK_EXEC_PER_FILE`).
    - Uses the **last** `--` as file separator so commands like `pnpm exec -- prettier --check -- {{files}}` are parsed correctly.
    - Used by `typos`, `pkl-format`, `editorconfig-check`, `shellcheck`, `shfmt`, `markdown-prettier`, `yaml-prettier`, `ruff_format`, `ruff`, `biome`, `json-biome`, `markdownlint-cli2`, `toml-taplo-check`, `toml-taplo-format`, `hadolint`, `dotenv-linter`.

- `eng/scripts/hk_pkl_eval.py`
    - Evaluates pkl files one by one, preserving failure output and handling quoted paths.

- `eng/scripts/hk_actionlint.py`
    - Adds file-level observability and timeout controls.
    - Supports env tuning:
        - `HK_ACTIONLINT_TIMEOUT_SECONDS`
        - `HK_ACTIONLINT_HEARTBEAT_SECONDS`
        - `HK_ACTIONLINT_SHELLCHECK`
        - `HK_ACTIONLINT_PYFLAKES`
