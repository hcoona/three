# Python Release Smoke

This dependency-free package is the Python proving payload for
[Workflow Delivery v3](../../../../../../../src/private/app/workflow-delivery/README.md).
Its installed API is `hcoona_release_smoke_python.project_id()`, which returns
`hcoona-release-smoke-python`.

The [ordinary Python release integration](../../../../../../../src/private/app/workflow-delivery/README.md#ordinary-python-release)
routes native versioning, wheel/sdist qualification and publication behavior.
The [current handoff](../../../../../../../src/private/app/workflow-delivery/docs/agent-handoff.md)
retains operation limits; the historical proving campaign remains closed.
This internal fixture has no production consumers or compatibility promise.
