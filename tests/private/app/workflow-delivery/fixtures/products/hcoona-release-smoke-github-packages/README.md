# Hcoona.ReleaseSmoke.GithubPackages

This operator-controlled smoke library validates Workflow Delivery v3 package
construction, clean local consumption before publication and GitHub Packages
publication with registry readback of the original bytes. It has no
production compatibility obligations.

`HcoonaReleaseSmokeGithubPackages.Smoke.ProjectId` returns
`hcoona-release-smoke-github-packages`.
