# Native Contract Fixtures

`pnpm-contract` and `npm-contract` are committed workspaces for the
`PnpmNativeContract` tests (`PnpmGraphContractTests`, `NpmPackContractTests`). The
[PNPM pin guard](../../../../../src/private/app/workflow-delivery/docs/research/pnpm-native-planning.md#pin-guard)
owns what they assert.

Each `pnpm-lock.yaml` was generated by the mise-locked PNPM from the workspace
root with local packages only:

```sh
mise exec --locked node pnpm -- pnpm install --lockfile-only --offline --ignore-scripts
```

Regenerate a lock only in a reviewed change, and remove any `node_modules`
the command creates. `pnpm-contract/vendor/archived-1.0.0.tgz` is a
reproducible local tarball input containing only `package/package.json`.
The tests copy a fixture into scratch before running PNPM, so they never write
here.
