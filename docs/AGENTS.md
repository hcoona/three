# Documentation Agent Routing

Read the accepted [record policy](governance/record-system.md) and
[Delivery Wave](delivery-wave.md), then use the [documentation portal](README.md)
and [family catalog](governance/record-families.yaml) to find the owning concern.
Repository guidance belongs in repository records; product requirements,
architecture and evidence stay with the project that owns them.

Apply record admission before creating a file. Preserve source identity,
evidence level, stable IDs, legal notices and current consumers when moving or
retiring records. Human-source inputs and raw assets are immutable unless the
owner explicitly authorizes their change. Git retains replaced history; current
work and review evidence belong in Issues/PRs rather than an append-only wiki
log or a second authorization record.

Use the root agent instructions' direct paths for independent record-system and
research-evidence review. New or edited prose is English. Do not turn retained
historical inputs into new product commitments or silently translate evidence.
