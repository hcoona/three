# Source Digests

Store one digest page per ingested source in this directory.

Recommended filename pattern:

- `yyyy-mm-dd-source-slug.md`

Recommended sections:

1. `Summary`
2. `Key Points`
3. `Important Claims`
4. `Related Pages`
5. `Open Questions`
6. `Source Location`

Digest pages should summarize the source faithfully, capture notable claims,
and link outward to concept, entity, and analysis pages.
