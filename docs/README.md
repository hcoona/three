# Docs Wiki

This directory is a starter LLM Wiki workspace.

It is organized into three layers:

- `sources/` for immutable, human-curated source documents;
- `raw/` for immutable supporting assets such as images and exports;
- `wiki/` for the LLM-maintained markdown knowledge base.

Use `AGENTS.md` as the operating contract for future ingest, query, and lint
workflows.
