## 2. Authority adjudication

Before plan authorship, independent ideal-first and adversarial repository-safe adjudications separated
six concerns:

| Concern                             | Authority                                            |
| ----------------------------------- | ---------------------------------------------------- |
| Exact identity and integrity        | Request SHA-256 over the original approved bytes     |
| Authorization and provenance        | Exact approval envelope and original A0 decision     |
| Rule grammar and document structure | Strict released `atlas-intake/v2` validation         |
| Historical definition mapping       | Exact approved groups, order, entries, and decisions |
| Current matcher compatibility       | Future mandatory live definition reconciliation      |
| Current membership                  | Future complete metadata-only definition enumeration |

Both adjudicators found that the historical replay predicate was designed to test one real but
misplaced property: whether today's matcher agrees with the approved classification over the finite
stored path set. Only completion would establish that finite agreement. G0R6 did not establish it, and
this record infers no private mismatch or cause. Even on completion, the predicate would prove neither
identity nor approval, could not prove behavior for novel paths or the current denominator, and would
give an evolving matcher a second veto over unchanged approved bytes.

The strict reader independently retains valid and unique group identifiers, rule grammar, unique source
aliases and normalized paths, nonnegative and reconciled group counts, entry-to-group references, valid
group and entry decision domains, entry/group decision agreement, file-only non-reparse entries,
manifest definition counts, and the approved definition-count, role/decision, and group-membership
reconciliation flags. The exact digest-bound `manual-a0` manifest and original project-leader approval
make the stored mapping normative historical evidence.

Both adjudicators retained current matching where it is operationally meaningful: future live discovery
must apply the approved ordered rules to the complete observed definition tree, reject missing and novel
paths, and require every current classification to match the approved mapping before content access.

The project leader approved:

- removal of current-matcher replay only from historical acceptance;
- no additional private replay, subgroup diagnostic, token, or state protocol;
- continued fail-closed matching only in future live definition reconciliation; and
- later separation of mutable save membership from immutable game-definition authority.

No adjudicator or reviewer accessed or inferred a private path, rule, mapping, difference, value, cause,
or individual refusal predicate.
