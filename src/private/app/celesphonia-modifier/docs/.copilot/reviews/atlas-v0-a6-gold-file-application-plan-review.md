Verified shared `R6R4` authorizes only a repository-safe synthetic implementation that:

- accepts one fully qualified exact `file1.rpgsave` through `file20.rpgsave` path on Windows;
- reads and models the source while denying write sharing;
- invokes the released G6R3 kernel;
- returns without artifact access for semantic no-op;
- creates one immutable adjacent archive backup before the first changed replacement;
- preserves that completed backup across later edits;
- creates or reuses one exact adjacent candidate stage;
- performs one same-directory `File.Replace` with no replacement-time backup;
- classifies returned and expected thrown replacement outcomes from exact filesystem bytes; and
- never automatically rolls back, deletes the completed backup, or adds a cleanup protocol.

The implementation is limited to one new production file, one new test file, and
`ProjectBoundaryTests.cs`. It adds no CLI, schema, request, project-file change, reader/kernel/seam
change, journal, ledger, transaction, recovery service, WinUI, or private execution.
